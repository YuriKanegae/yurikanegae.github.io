# kanegae.com.br

This is the source for the blog kanegae.com.br, main sources on:
- [Jekyll](https://jekyllrb.com/)
- [GitHub pagegs](https://pages.github.com/)
- [How to build a SQL blog - Chad Baldwin](https://chadbaldwin.net/2021/03/14/how-to-build-a-sql-blog.html)

## Local development
To install the jekyll and bundler gems:
```shell
gem install jekyll bundler
```

Build the site and make it available on a local server.
```shell
bundle exec jekyll serve
```
